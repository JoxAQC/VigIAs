# **App Name**: SJL Alerta

## Core Features:

- Authentication: Secure access using Firebase Authentication with mock user accounts for police, security, and mayor personnel.
- Interactive Map: Display simulated high-risk zones and recent alerts using the Google Maps API.
- KPI Dashboard: Show key performance indicators like total critical alerts, active hot spots, and available resources (security personnel, cameras).
- Alerts Table: Display a sortable table of alerts with key details such as type, classification, location, priority, and a Gemini-generated description.
- Gemini-Enhanced Alert Descriptions: Enrich original alert descriptions using mock Gemini API to provide additional context, possible actions, and classifications, simulating an AI analysis tool.
- Interactive Charts: Visualize incident classification and alert trends over time.
- Alert Management Simulation: Simulate alert management by allowing users to 'Manage Alerts'. The system acknowledges an action and simulates the assignment of the correct resource to that alert.

## Style Guidelines:

- Primary color: Lime Green (#70C63B) to represent safety and awareness.
- Background color: Light Cyan (#E0F8F5), creating a calming yet informative backdrop. This color is a lighter variant of the provided Azure Cyan, conveying a sense of calm and clarity for the authorities using the dashboard.
- Accent color: Vibrant Magenta (#E8208C) to highlight critical alerts and actionable items, drawing immediate attention.
- Body and headline font: 'Inter', a sans-serif font to provide a modern, machined, neutral look.
- Use consistent and intuitive icons for alerts, resources, and navigation to enhance user experience.
- Implement a responsive layout ensuring the dashboard is accessible and usable on various screen sizes.
- Add subtle animations to alert status changes or KPI updates for better visual feedback.
